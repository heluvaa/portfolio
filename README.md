# Zicoxbt Portfolio

Static single-page portfolio, dark elegant. Sticky numbered nav 01-06, RPG-inventory visual world where rarity tiers map 1:1 to verified truth:
- **LEGENDARY** (gold) = 3 audited-live Selected Work (Tempmail Inbox, Warkop Dua Tujuh, AirDrop Tracker Pro)
- **LIVE** (green) = HTTP-audited 200 links
- **SEGERA** (grey, sealed) = projects with no live link, no fake URLs
- **CONTOH** (purple) = clearly-labelled placeholder cards (Content & Appearances section)

Audited stats shown: 24 public repos (GitHub API), 15 live URLs (HTTP-200 verified), 0 PII exposed.

No PII. No invented numbers. All links HTTP-audited.

## Stack
HTML + CSS + vanilla JS, no build step. Self-hosted fonts (Chakra Petch + JetBrains Mono). Self-hosted avatar and project thumbnails.

## Files
- `index.html` (single page)
- `style.css`
- `main.js` (sticky nav sync, reveal-on-scroll, loot-card inspect, count-up)
- `img/` (avatar + 8 thumbnails + provenance sidecars for WebP)
- `fonts/` (7 woff2, latin subset)
